# PALM RUN · 棕榈街区

一个 GTA 风格的海滨街区单机原型。使用程序化街区和带骨骼动画的人物模型，在电脑浏览器里体验步行、驾驶和限时送货。

技术栈：**Vite 8 + TypeScript + Three.js + Rapier 3D**。界面使用 HTML/CSS，游戏在浏览器本地运行，生产构建可以静态部署。

## 快速开始

推荐 **Node.js 24 LTS**。Vite 8 要求 Node.js `^20.19.0 || >=22.12.0`。

```sh
npm ci
npm run dev
```

打开终端显示的本地网址，点击「进入街区」。首次运行需要下载 npm 依赖；游戏本身没有外部字体、模型或图片请求。

当前 Windows 机器的默认 Node.js 为 20.15，项目提供兼容启动脚本，会在需要时使用本机已有的 Codex Node.js 24 运行时，仅修改当前进程 PATH：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run.ps1 dev
```

也可将最后的 `dev` 替换为 `install`、`build`、`preview`、`typecheck` 或 `test`。其他电脑直接安装 Node.js 24 后使用标准 npm 命令。

## 操作

| 按键 | 步行 | 驾驶 |
| --- | --- | --- |
| WASD / 方向键 | 移动 | W 加速、S 刹车/倒车、A/D 转向 |
| Shift | 奔跑 | — |
| 空格 | 跳跃 | 刹车 |
| F | 靠近车辆上车 | 停车后下车 |
| E | 靠近任务点接单 | 靠近任务点停车接单 |
| V | — | 切换车外跟随 / 车内驾驶视角 |
| [ | — | 上一首（暂停界面也可用） |
| / 或 ] | — | 下一首（播完自动切下一首，暂停界面也可用） |
| M | 音乐静音 / 恢复 | 同左 |
| 鼠标左键拖动 | 转动跟随镜头 | 车外环视 / 车内左右看，松开后逐渐回正 |
| R | 将角色和车辆重置到街角 | 同左，任务计时继续 |
| Esc / 右上角暂停 | 暂停或继续 | 同左 |

点击页面进入后使用键盘。切换窗口或隐藏页面会自动暂停，恢复后点击继续。

打开首页即尝试循环播放 Oh No 的《Welcome to Los Santos》。首页、暂停界面和车内均可切歌，菜单和车载歌单分别记住本次选择。可用 `[` 上一首、`/` 或 `]` 下一首，或点击右侧电台按钮切歌；歌单还包括《Self Control》《Out of Touch》《It Was a Good Day》。步行时停止音乐并隐藏音乐面板；首页、暂停界面和上车后播放并显示音乐面板。步行中暂停会恢复菜单中选择的歌曲，继续步行再次静音；车内暂停/继续保留当前歌曲与进度。下车或重置后停止音乐；若浏览器拦截有声自动播放，点击页面任意位置或按键即可开启。右侧电台支持调节音量和静音，音量偏好保存在本机。音频从 `public/music/` 本地加载，来源记录见 [音乐说明](public/music/ATTRIBUTION.md)。

步行与车外跟随镜头采用较低、接近平视的角度。上车默认使用车外视角，按 V 进入驾驶席，可看到透明车窗、仪表台和随转向转动的方向盘。下车或重置后恢复步行视角；暂停保留当前视角。

## 怎么玩

1. 前往附近绿色光圈，按 E 接取送货任务。
2. 回到浅绿色汽车旁，按 F 上车。
3. 沿道路开到小地图上的绿色目标，在 120 秒内驶入光圈并减速停车。
4. 成功送达获得 $250；现金和累计送货次数会自动保存到当前浏览器。
5. 可以返回取件点重复接单，也可以自由探索。

左下角圆形雷达：白色箭头为玩家、蓝色标记为汽车、粉色菱形为当前目标。雷达以玩家为中心随视角旋转，N 标示北方；超出范围的任务目标会在圆边提示方向。

右上角复古 HUD 显示固定场景时间 18:42、实时现金与空手图标。生命值 100、护甲 000 和六颗未点亮通缉星是后续系统的预留显示，目前没有伤害、护甲或警察追捕逻辑。

## 当前版本

- 程序生成的海滨街区：道路、建筑、店铺招牌、棕榈树、海面、夕阳与阴影。
- 第三人称角色：Quaternius 休闲装 GLB 人物，待机/步行/跑步动画混合、跳跃、Rapier 碰撞、跟随镜头。
- 同一人物上下车：上车后坐在驾驶席，手臂跟随方向盘；车内视角保留手臂，隐藏遮挡镜头的头部/躯干，下车恢复完整人物。
- 一辆可驾驶汽车：上下车、加速、倒车、转向、刹车、碰撞与重置，支持车外/车内视角切换。
- 一个限时配送循环：接单、目标切换、送达奖励、超时重试。
- HUD、小地图、暂停、加载/错误提示、本地存档。

警察追捕、行人交通、引擎/碰撞音效和真实车辆悬架尚未实现。当前车辆是简化刚体街机控制；这里只锁定车身俯仰/翻滚，并不模拟完整轮胎和悬架。手机触控不在首版范围。上下车目前直接切换位置和姿态，尚无开门/入座过渡动画。

人物使用 Quaternius 的 Casual Character（CC0），模型随项目本地部署，约 1.43 MB。来源、授权、校验值和运行时改动见 [模型说明](public/models/ATTRIBUTION.md)。

## 检查与构建

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

`build` 会先执行 TypeScript 检查，再输出 `dist/`。测试覆盖配送计时、奖励去重与存档异常处理。浏览器验收步骤见 [测试清单](docs/TESTING.md)。

Rapier compat 包内嵌 WASM，游戏模块体积较大，Vite 可能给出 chunk 体积提醒；这是首版已知优化项，详细说明见 [技术方案](docs/ARCHITECTURE.md)。

## 代码结构

```text
src/
  core/       游戏循环、输入、任务状态、存档
  actors/     角色和车辆
  world/      街区、碰撞体、任务标记
  ui/         HUD、小地图、开始和暂停界面
  main.ts     页面入口、异步初始化
  style.css   界面样式
public/       随构建发布的静态资源
scripts/      Windows 启动脚本
tests/        游戏状态测试
docs/         大纲、架构、部署和验收文档
```
