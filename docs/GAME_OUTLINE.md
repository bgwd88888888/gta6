# 游戏大纲与开发阶段

更新：2026-09-19。项目代号：**PALM RUN / 棕榈街区**。

## 定位

一款以小型海滨街区为舞台的第三人称单机浏览器游戏。核心体验是自由探索、轻松驾驶、完成差事，并在后续加入简单警察追逐。一局目标体验约 5–10 分钟，可以重复游玩。

美术采用原创低多边形风格，主题为夕阳、棕榈树、粉彩建筑和沿海道路。程序生成资源作为第一阶段可玩原型，后续替换为有统一比例的 GLB 资源。

## 核心循环

探索街区 → 找到差事 → 接取任务 → 上车驾驶 → 到达目标并停车 → 获得金钱 → 继续探索或再次接单。

追捕阶段在该循环上增加事件：触发通缉 → 警车追赶 → 拉开距离并保持 → 解除通缉。追捕不属于当前代码的已完成功能。

## 地图设计

- 三条纵路和三条横路构成可循环驾驶的道路网。
- 出生点在中心道路，附近提供汽车与取件标记，减少初次操作成本。
- 海滨配送点位于东北侧道路，让任务自然引导玩家穿越街区。
- 建筑使用简化碰撞体，地图外围通过边界阻挡防止跌落。
- 当前海面为装饰，不包含游泳或水面物理。

## 玩法规则

- 只有接单后才可获得配送奖励；送达只结算一次。
- 到达目标半径 5 米内且车速低于约 9 km/h 才能完成配送；步行送达也有效。
- 任务进行中重复接单不会补充计时。
- 暂停和切到后台时任务计时停止。
- R 重置角色与车辆，保留当前任务与剩余时间，避免重置刷奖励。
- 高速时禁止下车；下车前检查落点空间。
- localStorage 不可用时可以继续游玩，但不会跨刷新保留本次奖励。

## 开发阶段

### 阶段 1：项目和街区原型（本轮）

建立工程、文档、游戏循环和可玩街区，串通角色、车辆、任务。完成构建检查、状态测试和浏览器试玩验证。

### 阶段 2：驾驶与镜头打磨

增加车辆地面检测与轮胎模型，优化转向、碰撞和镜头遮挡；引入模型动画、音效和画质设置。验收目标：连续驾驶一圈、上下车、贴墙移动、切窗恢复均稳定。

### 阶段 3：轻量城市追逐

构建可复用道路路点图；用巡逻、追赶、搜索、解除状态管理一辆警车。明确触发规则、逃脱条件、被捕重置和罚金。验收目标：完整经历一次触发、追捕、逃脱或被捕。

### 阶段 4：发布试玩

压缩模型纹理、资源分批加载、处理缓存和加载失败、设置发布流程。先发布可分享试玩链接，再根据玩家地区确定正式域名和 CDN。
