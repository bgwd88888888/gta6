# Sunset visual direction

The entrance uses a GTA VI-inspired fan-made poster layout: stacked outlined lettering, gradient VI, a pastel sunset boulevard, adult protagonists, a vintage muscle car and palm silhouettes. Desktop puts the title beside the characters; narrow screens stack artwork and content. The playable prototype retains its existing controls and saves.
